# Libre 3 → Health OS — Setup

Подключаем CGM Libre 3 к боту через LibreLinkUp. После настройки бот:

- автоматически синкает показания каждые 15 минут в Supabase
- по запросу строит график глюкозы с маркерами еды поверх кривой
- умеет считать постпрандиальный ответ на конкретный приём пищи
- знает текущий уровень и тренд при логировании еды

## 1. Создать второй аккаунт LibreLinkUp

Это обязательный шаг — Abbott не даёт API доступа к собственному аккаунту,
только к расшаренному. Сценарий: ты на одном email пользуешься LibreLink (где
сенсор), и расшариваешь данные на **второй** email, через который будет ходить бот.

1. Создай новую почту (любая, удобно использовать `+`-алиас:
   `youraddress+libre@gmail.com`). Запомни её и придумай пароль.
2. На iPhone открой App Store → установи приложение **LibreLinkUp**
   (отдельное от LibreLink, иконка с двумя стрелками).
3. В LibreLinkUp зарегистрируйся на эту вторую почту, заверши onboarding.

## 2. Расшарить сенсор из LibreLink

1. Открой основной **LibreLink** на iPhone (тот, где сенсор активен).
2. Меню → **Connected Apps / Подключённые приложения** → **LibreLinkUp** →
   **Connect to LibreLinkUp**.
3. Введи email второго аккаунта и подтверди.
4. В LibreLinkUp на телефоне нажми **Accept Invitation** во входящих
   приглашениях.
5. Проверь, что в LibreLinkUp видны твои текущие показания глюкозы.

## 3. Положить креды в Health OS

Создай файл `config/libre_credentials.json` со вторыми кредами:

```json
{
  "email": "youraddress+libre@gmail.com",
  "password": "пароль"
}
```

Или (если деплой через Railway) — задай переменные окружения:

```
LIBRE_EMAIL=youraddress+libre@gmail.com
LIBRE_PASSWORD=пароль
```

Env vars имеют приоритет над файлом.

## 4. Применить миграцию схемы в Supabase

В Supabase Dashboard → SQL Editor → выполни `supabase_schema.sql` целиком (или
только новый блок про `glucose_readings`).

## 5. Проверить

```bash
cd "Health OS/bot"
python3 -c "import asyncio, libre; print(asyncio.run(libre.sync_recent()))"
```

Ожидаемый ответ — словарь вида:

```python
{'written': 96, 'latest': {'ts': '...', 'mmol_l': 5.4, 'trend': 'stable', ...},
 'range': {'from': '...', 'to': '...', 'count': 96}}
```

Если получил `RuntimeError: LibreLinkUp returned no connections` — значит
расшаривание в LibreLink не дошло до второго аккаунта. Повтори шаг 2.

## 6. Использование в Telegram-боте

После перезапуска бота:

- **`/glucose`** — график за последние 12 часов с маркерами еды + интерпретация
- **`/glucose 6`** — то же за 6 часов
- В свободной форме: «какая сейчас глюкоза?», «покажи график за день»,
  «как я отреагировала на завтрак?» — Coach сам вызовет нужный tool.

Сам синк работает в фоне каждые 15 минут, так что данные всегда свежие
без явных команд.

## Ограничения

- LibreLinkUp API — неофициальный (community reverse engineering). Если Abbott
  поменяет схему, может временно сломаться: обычно фиксится обновлением
  заголовков `product` / `version` в `bot/libre.py`.
- Лаг ~1 минута между показанием сенсора и доступностью в API.
- Если использовать тот же второй аккаунт ещё откуда-то (Nightscout, xDrip),
  может появляться 429 (rate limit). На один поллер хватает с запасом.
