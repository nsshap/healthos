Health OS

Персональная система здоровья: стратегия + тактика + данные

github.com/nsshap/-healthos

Идея

Два слоя по методологии Medicine 3.0 (Peter Attia) и тренировочной науки:

Стратегия The Board
Риски на годы вперёд, биомаркеры, директивы CMO, долгосрочные цели.
Тактика The Field
Ежедневные калории, тренировки, сон, логи — исполнение плана.

Иерархия: директивы CMO > предпочтения пользователя > дефолтные расчёты.

Как это работает в проде

  • Telegram-бот — основной интерфейс: команды и свободный диалог.
  • OpenAI (GPT-4o) — ответы и tool-calling (логи еды, Oura, рецепты и т.д.).
  • Supabase — рецепты, дневные логи, кольцо Oura, таблица research_items.
  • Файлы Health OS — профиль, директивы, стратегия, программа тренировок (YAML/Markdown в репозитории).

Деплой бота: Railway (сервис запускает python bot/bot.py).

Research Scout — зачем

Автоматически собирать свежие материалы по сну, метаболизму, кардио, силе и longevity, оценивать релевантность под ваш профиль и раз в неделю выдавать сводный дайджест на русском.

  • Каждый день: обход RSS → дедупликация → скоринг (модель) → запись в БД.
  • Раз в неделю (воскресенье): топ статей за 7 дней → синтез в Telegram + ссылки на источники.

Как устроен пайплайн исследований

  1. С каждого фида берётся до 10 свежих записей; статьи с уникальным URL попадают в обработку.
  2. Скоринг 0–10 по профилю (Medicine 3.0, сон, метаболизм, ApoB/VO2, сила и т.д.).
  3. Сохранение в Supabase; в воскресном дайджесте — статьи с score ≥ 6, топ-7 для текста + ссылки.
  4. Ручные команды в боте: /digest, /research, /research run.

Расписание на сервере (UTC): ежедневный скаутинг ~05:00; воскресный дайджест ~10:00.
